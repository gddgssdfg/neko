# 专注陪伴

从猫的右键菜单「专注 N 分」或托盘「专注计时」打开面板，点击开始。设置 → 番茄钟可分别保存专注与休息时长；更改从下一阶段生效。

- 暂停不计入时间，继续后从剩余时间接着走。重复打开面板不会重置计时。
- 专注完成后手动开始休息，也可以跳过休息开始下一轮；休息结束后等待手动开始专注。
- 锁屏或休眠会暂停正在运行的专注/休息，回来后在面板手动继续。
- 关闭面板后仍继续计时；停止、禁用插件或退出程序会清除当前进度。完成轮数只统计本次运行。
- 在待办中选中一条未完成事项，点击「专注选中待办」。已有计时进行时保留当前计时；番茄钟未启用时显示提示。计时完成不会自动勾选待办。

猫在专注时使用工作姿态，暂停或休息时坐下，不改动工作模式和键盘显示偏好。抚摸、拖动、落地和贴边优先；空闲后再回到陪伴姿态。此流程中普通闲聊和其他休息提醒暂缓，结束提醒遵守安静模式、全屏和通知间隔。

当前不提供跨重启进度恢复、专注历史、自动完成待办或自动循环。所有功能离线可用，不要求账号。

开发接口在 `DesktopPet.Core` 中：`CompanionEvents.FocusChanged` 广播只含共享类型的 `FocusSnapshot`；待办通过 UI 线程同步发送 `FocusTaskRequest`，接收方在返回前填写结果。不得保留请求对象、将任务标题写入公共日志或在通知中透露任务内容。
