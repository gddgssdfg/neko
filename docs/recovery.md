# 常驻与恢复

设置 → 通用 → 常驻与恢复：

- **安静模式**：停止猫的气泡和插件托盘提醒；退出安静模式不会补发。全屏游戏模式激活、锁屏或猫被隐藏时同样抑制通知。宿主两个通知通道共享十秒间隔。
- **电池省电**：电池供电时猫的循环间隔为 150ms；正常活动 50ms、空闲 100ms；隐藏、锁屏或暂停时 1000ms 且不推进动作。它不强制停止插件后台任务。
- **找回猫咪**：停止未完成的移动，回到主屏并重新对齐键盘；全屏自动隐藏和锁屏时不会强行露出。托盘也有入口。
- **备份**：导出外观、称呼、互动、通知、热键等偏好。它不是完整用户数据备份，不包含插件数据、凭据、未知扩展字段、插件启用状态、位置及开机自启。
- **导入**：预览确认后保存待导入文件。下次正常启动合并偏好，先在数据目录保留 `config.json.before-import-*`，再应用；当前运行期间仍可修改设置。无效导入不会覆盖当前配置，设置页可取消待导入。
- **恢复默认**：暂存默认偏好，下次正常启动应用；保留插件数据、插件启用状态与开机自启。
- **安全模式**：设置页可重启切换；程序无法正常打开时，在程序目录运行 `Neko.exe --safe-mode`。所有插件暂不加载，默认皮肤代替自定义皮肤；不改原插件开关、皮肤选择和径向菜单配置。安全模式不应用待导入文件，不自动检查更新。正常启动恢复原设置。

自动备份原配置仅保存在本机数据目录，不自动上传。原配置可能含扩展字段，请不要未经检查直接公开。偏好导出包含你设置的称呼与热键，分享前也可自行查看。

显示变化恢复会清除工作区缓存，并按窗口当前 DPI 在最近显示器内调整位置。真实多屏热插拔、远程桌面和混合 DPI 仍需要在对应设备上验证。
