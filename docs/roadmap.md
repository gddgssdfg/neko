# Neko 长期路线

更新于 2026-10-27。定位：原创像素橘猫、低打扰工作陪伴、可定制外观和开放扩展。按阶段完成标准推进，不承诺固定日期。

| 阶段 | 工作 | 完成标准 |
| --- | --- | --- |
| 可靠常驻（已完成首批） | 屏幕变化恢复、锁屏和唤醒、安静模式、电池省电、设置备份、安全启动 | 自动回归覆盖状态组合和数据保护；真实多屏热插拔与长时间运行另行实机验证 |
| 角色精品化（进行中） | 动作参数和可中断过渡已接入；继续打磨原创橘猫比例、调色板及专门的过渡帧 | 默认大小表情清楚，切换自然，换皮肤后眼睛和步幅准确 |
| 工作陪伴 | 专注、待办、休息提醒联动；可选轻养成；整理默认功能入口 | 新用户能完成一个专注—休息流程，不依赖网络，不强制签到 |
| 创作者工具 | 动作预览、锚点与眼睛区域编辑、打包校验、示例和版本规范 | 外部作者按文档独立制作可安装皮肤或插件 |
| 稳定分发 | 干净机器安装升级、脱敏诊断、预览/稳定渠道、贡献流程 | 可持续支持陌生用户，兼容承诺有测试覆盖 |

本轮范围：锁屏暂停的是宿主动作与伴随窗口，不停止所有插件后台任务；安静模式约束宿主气泡和托盘 API，不是任意第三方 DLL 的执行沙箱。安全模式跳过所有插件，也跳过待导入设置与自动更新，普通启动恢复配置。

角色精品化首批（v0.6.0）：[动作参数与过渡契约](skin-motion.md)，以及抚摸反应中断保护、唤醒与工作姿态恢复。本轮复用现有坐姿素材；专门绘制的睡醒/趴下帧、美术比例规范和创作工具尚未完成，不把参数接入当作整阶段完成。

后续可靠性工作：真实混合 DPI 多屏矩阵、长时间运行与耗电基线、干净系统安装升级、脱敏诊断。自动化窗口消息测试不代替真实设备验证。

扩展路线先做皮肤工具，再做社区目录。DLL 插件当前进程内运行；后台任务进程隔离需要明确 IPC 和权限模型，不能把 ALC 或独立进程本身称为安全沙箱。保留现有 WPF 插件兼容路线。

跨平台重写、大型插件商店、账号/多人交易、默认 AI 和复杂 3D 暂缓。新增功能优先回答：是否让猫更有生命感、是否改善长期常驻、是否帮助创作者。

产品路线参考（2026-10-26 调研，非市场份额结论）：[Bongo Cat](https://store.steampowered.com/app/3419430/Bongo_Cat/)、[VPet](https://store.steampowered.com/app/1920960/VPet/)、[Desktop Mate](https://store.steampowered.com/app/3301060/Desktop_Mate/)、[开源 BongoCat](https://github.com/ayangweb/BongoCat)。
