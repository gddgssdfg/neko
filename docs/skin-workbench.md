# 皮肤工作台（v0.8.2）

打开「设置 → 外观 → 皮肤工作台」检查当前皮肤，也可选择其他包含 skin.json 的目录。导入皮肤时，预览窗口中的「检查全部动作」会打开同一工作台。无需先安装或替换当前皮肤。

## 检查动作

- 动作列表包含九种基础动作和清单中的附加动作，过渡帧也可单独选择。
- 播放/暂停、上一帧/下一帧，以及 0.5×/1×/2× 速度均只影响预览。逐帧会暂停；继续播放从所选帧开始。fps=0 的动作保持静止，但仍可逐帧检查。
- 棋盘表示透明背景；红框标出源画幅，蓝框是当前眼层非透明像素的联合包围盒，蓝色十字表示眼层原点。锚点坐标来自该动作当前帧的 eyeOffsets，单位为源像素。
- 这里展示原始身体帧与声明眼层，不叠加随机眨眼、呼吸、影子或自动过渡；可在检查面板单独模拟视线。因此包围盒不是眼眶遮罩，也不代表眼球最大安全位移。运行时表现仍需装入程序检查。
- 外部修改完成后点击「重新校验」。失败会显示原因并保留上一份可用预览；暂停、静态动作、最小化和关闭窗口时停止预览计时器。

基础检查复用导入逻辑：目录与 id、声明、九种动作、帧数、图像解码和尺寸。所有文件还须通过导入包文件类型、数量和大小限制。`frameWidth/frameHeight` 是源图单帧像素尺寸；独立帧布局也必须准确声明，不是固定填写 32。宿主逻辑画幅仍为 32×32。

作者提示还会检查缩略图缺失、声明眼层不可用或尺寸异常，以及 fps>0 时所有身体帧相同。提示不会自动修复，也不阻止打包；逐帧锚点变化可能让相同身体帧仍有眼层动画，需要作者判断。像素重复检查设有总像素预算，大素材会明确提示跳过，不把未检查说成通过。

## 编辑眼层锚点

1. 选择有独立眼层的动作和帧，勾选「编辑眼层锚点」。播放会暂停；没有独立眼层的动作无法在这里编辑眼睛。
2. 拖动蓝色眼层包围盒，或输入 X/Y 后点击「应用坐标」。坐标单位为源像素，拖动以 1 源像素吸附；数值输入支持小数，使用英文句点。坐标须为有限数字，X/Y 分别不超过源画幅宽/高的正负范围。
3. 每次拖动从按下到释放只记为一次修改；按 Esc、失去鼠标捕获或切换帧会取消尚未结束的拖动。「撤销 / 重做」会定位到被修改的动作与帧；「还原本帧」恢复到本次加载或最近一次保存的坐标。
4. 修改先留在内存草稿中。点击「保存锚点」后，工具校验私有副本，将完整原清单备份至数据目录 `host/skin-backups/<id>/<唯一编号>/skin.json`，再原子替换源目录中的 `skin.json`。PNG 不改写，未知 JSON 字段保留；JSON 排版可能变化。
5. 如果清单在外部被修改，会拒绝覆盖并保留草稿。备份失败或校验失败也不会清空草稿。保存后撤销历史清空，以新保存内容作为还原基准。需要恢复旧版时，关闭工作台，将对应备份的 skin.json 复制回原皮肤目录，再重新校验。

有未保存修改时，标题显示「未保存」，导出按钮禁用。关闭、重新校验或换目录时可选择保存、放弃或取消。草稿不跨重启保存。工作台保存不会自动替换正在使用的猫；回到外观页点击「刷新皮肤」加载变化。

锚点平移的是整个眼层，蓝框仍不是眼眶遮罩，也不保证移动后眼睛一定处于眼眶内。视线与运行时遮罩可在下面的检查面板中预览；眼眶遮罩编辑仍未实现。

## 检查视线与遮罩

展开「眼神位移与遮罩检查」，勾选「模拟视线」。预览暂停并退出锚点拖动编辑；猫旁边会出现九个方向按钮。按钮模拟最大方向视线，居中按钮回到中性位置，均不写入清单或草稿。检查时也可继续播放身体帧观察逐帧锚点。关闭模拟即可回到源素材预览。

- **蓝框**：当前眼层平移后的非透明像素包围盒，不是眼眶形状。
- **橙色椭圆**：瞳孔包围盒中心相对锚点的位移范围；数值使用源像素，沿用 motion、素材限幅和主程序的椭圆约束。
- **绿色区域**：运行时使用的 `<eyeLayer>_closed` 图层 alpha 遮罩，不是自动识别的真实眼眶。
- **裁剪前对比**：有遮罩时可打开半透明原眼层，观察哪些部分被裁掉；无可用遮罩时禁用该选项。

缺少遮罩的皮肤仍使用保守限幅，但工具会明确提示无法自动确认眼眶安全。有内嵌眼睛、眼层缺失或眼层/身体尺寸不一致时不提供模拟。闭眼、半闭和抚摸表情按主程序规则固定眼层。未裁剪眼层的包围盒超出源画幅时会提示检查锚点。

主程序逻辑画幅为 32×32，非正方形源图会分轴换算位移；预览显示换算后的源像素数值。为贴近主程序亚像素移动，常规尺寸的模拟眼层先在源像素层计算滤波并缓存，再按皮肤的像素/平滑方式放大，避免把像素眼睛整体放糊；身体缩放方式保持原样。此预览不模拟随机眨眼、打字、呼吸或行走镜像，完整效果仍须在主程序试用。

遮罩随锚点一起移动，错误锚点可能让整只眼睛移到脸外，即使有裁剪也不能视为安全保证。请逐帧核对五官位置；工具不会自动修改坐标、生成遮罩或改写图像。

## 导出与接入

1. 整理一个只含所需 PNG、JSON、说明及许可文件的皮肤目录，检查全部动作和作者提示。
2. 点击「导出皮肤包」，在素材目录之外选择一个新的 .zip 文件名。已有文件不会被覆盖。
3. 工具先复制到私有临时目录，重新按导入契约校验副本，再写出 ZIP；失败会清理临时副本，不修改源素材。
4. ZIP 包内是 `<id>/skin.json` 和配套文件。接收者先解压，再在「导入皮肤」中选择包含 skin.json 的目录；当前不直接导入 ZIP，也不覆盖已安装的同名皮肤。

导出时会包含目录内所有符合导入类型规则的文件；请先整理目录并保留必要许可。预览不是素材授权证明，发布前仍须确认使用与再分发权利。

目前不提供眼眶遮罩编辑、动作重绘或运行时过渡串联预览。字段说明见 [皮肤开发标准](skin-development-guide.md) 和 [动作参数与过渡](skin-motion.md)。
