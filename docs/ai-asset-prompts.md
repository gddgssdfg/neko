## 🚨 与上一版的 3 个关键变化（先读这段，避免白做）

| # | 变化 | 原因（实测） |
|---|---|---|
| 1 | **动画一律走「图生视频 + 抽帧」**，不再画「横向 N 格序列条」 | 图像模型画多格时**每格都会重新构形**，实测相邻帧差异 **13~42%**，播起来必跳。试了 3 次（v1 六格 / v2 八格 / 明确写"每帧只动 1/12 身高"）都失败——**这是图像模型的固有限制，不是 prompt 问题** |
| 2 | **静止态只画 1 张静态图**（待机/坐/睡），靠引擎 `fps=0` + 程序呼吸/眨眼 | 猫大部分时间**本就该不动**；一直动反而假、还费 CPU。实测静止态闲置 CPU 增量 **0.00%** |
| 3 | **同一对「睁眼图 + 闭眼图」现在产出 3 样东西**（不是 2 样） | 新增「闭合层」用于**眨眼**——见 §3.2。这是让角色"不呆板"的关键，且**不用再多画一套** |

> ❌ 因此：旧版「块 3 / 块 6 序列条」「块 2 / 块 5 闭眼九宫格」**全部作废，不用再做**。
> ✅ 保留的硬规则：**闭眼版必须和睁眼版是同一张画**（跨批次画 → 瞳孔差分错位成漂浮色斑，实测橘猫 idle 差 42.7）。

## 附录 A：命名约定（闭眼版 → 瞳孔层 + 闭合层）

「同一对睁/闭眼图」在管线里产出两个叠加层，**都与身体帧同画布、同坐标**，因此天然对齐：

| 层 | 文件名（`_airaw` 里是 `{c}_still_<state>_closed.png`） | eyeLayers key | 用途 |
|---|---|---|---|
| 瞳孔层 | `neko_eyes_<state>.png` | `eyes_<state>` | 眼神追踪（只取瞳孔） |
| **闭合层** | `neko_eyes_<state>_closed.png` | `eyes_<state>_closed` | **眨眼**（取闭眼图的眼睛区域） |
| 半闭层（可选） | `neko_eyes_<state>_half.png` | `eyes_<state>_half` | 更柔的眨眼过渡（**非必需**） |

**引擎侧约定**（已实现，见 `PetRenderer.Draw`；本文件只定命名）：
- key = `state.EyeLayer + "_closed"`（如 `eyes_idle` → `eyes_idle_closed`）。
- 实际兜底链（`Draw` 内）：
  - 半闭相位：`<EyeLayer>_half` → `<EyeLayer>_closed` → 全局 `eyes_half` → 全局 `eyes_blink` → 本状态睁眼层
  - 闭合相位：`<EyeLayer>_closed` → 全局 `eyes_blink` → 本状态睁眼层
- **必须保留兜底链**：缺素材要"保持有神"，**绝不能变成眼睛空白**（v0.1.86 刚修过这个坑）。
- 因此**闭合层已足够**（顶替半闭+闭合两个相位）；`_half` 是可选增强。

**为什么成立（判断）**：
- ✅ 闭合层与身体帧**同源同坐标** → 叠加天然对齐，不存在跨批次错位（§7.2 的坑）；
- ✅ **per-state**（`eyes_idle_closed` / `eyes_sit_closed`）→ 绕开"一个全局 blink 层必然错位一只眼"的死结（待机与坐姿眼睛位置不同）；
- ✅ **零额外生成**（复用已画的闭眼版）→ "一份素材支撑三项功能"成立。
- ⚠️ **前提**：① 引擎按上述约定接线（**已实现**）；② 管线导出闭合层（`build_skin_v2.py::extract_closed_layer`，**已实现**——用睁/闭差分掩膜取闭眼外观，膨胀抗眼神偏移 ±2px、羽化消硬边，区域外透明）；③ 闭合层要覆盖**眼白**（实测用差分掩膜 + 轻微膨胀即可，不能只取那条闭眼弧线，否则底下眼白会露出来）。
- ⚠️ **覆盖不到的状态**：动画态（walk/pet/…）眼睛画在身体帧里、无闭眼版 → **没有闭合层、不眨眼**（保持有神，符合预期，不做额外生成）。
