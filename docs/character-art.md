# 橘猫美术基准与后续动作制作

本轮保留已选外观，不重新生成整只猫。低分辨率基准为 `neko-assets/pixel/` 的身体与独立眼层；64px 重绘风格参考 `neko-assets/pixel_redraw/`，品牌头像参考 `neko-assets/branding/`。手绘皮肤保持自己的绘制方式，不强制转为像素稿。

## 原始像素猫的基准调色板

以下颜色直接读取当前 idle 身体素材的非透明像素，不是新指定的重绘配色：

| 角色 | 色值 |
| --- | --- |
| 橘色毛发 | #F7A33F |
| 暖棕轮廓 | #3A2A20 |
| 奶油白 | #FFF0D4 |
| 深橘条纹 | #D47A28 |
| 粉色细节 | #F2A0A0 / #E88B8B |
| 浅色阴影 | #E8DCCB |

制作新帧时保持耳尖、脸宽、额纹、口鼻和躯干比例一致。眼睛单独移动时始终相对该帧头部锚点定位，眨眼和微笑层不作为瞳孔滑动。应先固定骨架与调色板，再制作动作，避免逐帧重新生成导致换脸、毛色闪烁。

## 动作验收

- 待机：32px 原画及默认显示倍率下都能辨认猫耳、口鼻和眼神，不靠大幅全身晃动制造活动感。
- 工作：敲键盘反馈与轻微起伏分开，输入停止后自然收尾；脸和眼层必须一起移动。
- 抚摸：连续操作延长最新反馈，结束后回到此前使用的工作/待机模式，不能覆盖拖拽。
- 睡醒：先有清楚的坐起或抬头动作，再进入站姿或工作；静态皮肤可以保持立即切换。
- 行走：先做好脚掌接地与离地动作，再根据实际步态校准每周期步幅。当前参数是创作接入点，不代表所有旧素材已做到零打滑；自动走动默认关闭。
- 默认大小、100%/125%/150% DPI、深浅桌面背景都需要看实际效果。高倍率预览仅用于观察细节。

v0.6.1 已为原始 pixel 皮肤制作趴下入睡、坐起苏醒（待机/工作）和抚摸结束收势（待机/工作）五组专用四帧动作，复用上述部件和调色板。新帧采用纯硬边、二值透明，原有十组动作与眼层保持不变。

后续专门美术工作：其他画风的独立过渡帧，以及耳朵/尾巴的小动作。新增中间动作通过 [过渡契约](skin-motion.md) 接入，不需要增加 Core 的 PetState 枚举或修改插件 API。

v0.8.3 已重绘琥珀待机与工作帧，采用短促眨眼、左右爪交替敲击和输入休息帧。[素材与提示词记录](amber-animation.md)。步态、睡醒和抚摸收势仍是后续工作，不能把这两组升级等同于整套动作完成。

v0.8.4 已重绘琥珀四帧步态，包含单独绘制的反向落脚姿态；补齐右向原画声明，左右移动时镜像。6fps 配合 12.5 逻辑像素步幅，在 4 倍率/普通情绪下约 75 DIP/s。[步态素材与提示词](amber-walk.md)。这仍是四帧关键姿态，不承诺脚掌在整个接地期完全无滑移；其他动作和皮肤未在本批更新。
