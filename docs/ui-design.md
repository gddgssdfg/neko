# 伙伴界面与插件 UI

v0.3.0 将界面基础层放入 `DesktopPet.Sdk`，宿主、内置插件不再各自维护一套蓝灰色画刷和默认按钮。业务状态、配置格式、插件权限和 B01 素材不变。

## 共用层

- `NekoPalette` 提供浅色、深色语义色和冻结画刷缓存。
- `NekoDesign.Apply(window)` 为窗口安装按钮、输入框、下拉框、列表、展开区的资源与模板。调用方仍负责自己的布局及业务回调。
- `NekoDesign.LightTheme` 由宿主配置初始化；`RefreshWindows` 更新已接入窗口的主题资源及共享画刷，保留自定义画刷。
- `NekoSwitch` 基于标准 `ToggleButton`，支持 Tab、Space 与 UI Automation TogglePattern。`IsOn` 用于无回调地同步状态；用户和辅助功能操作触发一次 `Toggled`。
- `PluginUi` 工厂跟随当前主题；原有公开画刷字段保留，避免旧插件二进制缺失字段。`ShowStatus(panel, message, error)` 在表单内显示保存反馈，不打断输入焦点。

独立插件窗口应在构造时调用 `NekoDesign.Apply(this)`。第三方自定义颜色和图片仍归插件管理；宿主仅在嵌入设置时映射旧 SDK 共享画刷。不要把插件自己的品牌色强制替换成主题色。

## 页面与生命周期

设置页仍按栏目缓存，外部状态签名或启停操作使对应栏目失效。主题和语言变化重建外壳与页面。插件设置仅在首次展开时构建；切页再回来复用内容，所以插件必须支持 `Unloaded → Loaded`，不能把可复用表单的事件所需对象清空。

命理设置的预览计时器改为每个内容实例独立持有，卸载时停止，重新编辑时可再次启动。停止的计时器不会继续注册在 Dispatcher 中，也不会将其他表单绑到同一个字段上。

键盘仍直接消费全局钩子事件，不主动模拟输入。虚拟键与图例一一对应；主题刷新重建键帽映射并停止瞬态动画计时器，保留全局事件订阅和锁键轮询，关闭时沿用原有解绑逻辑。

```powershell
python tools/ci.py

```

后者使用临时数据目录，输出六个设置栏目、最窄窗口、插件展开区和七种独立界面的明暗主题 PNG。数据操作回归使用本地回调，咨询预览不请求模型服务。测试素材与预览不进入运行包。


### v0.3.3 浮层与鼠标

宿主径向菜单使用固定 32 DIP 内圈，独立于猫咪缩放。`CompanionLayout.Place` 枚举工作区和猫、键盘、爱心窗口周边空位，优先避免交叠，再选择接近猫的位置；位置同步先摆键盘再摆菜单。屏幕空间确实不足时暂时收起键盘，菜单关闭后按当前模式恢复。打开菜单收起气泡，期间暂缓新气泡。单独调用 `RadialMenu.ShowAt` 仍支持以指定圆心展示。

键鼠面板保留 74 键布局，右侧使用独立鼠标垫。全局钩子仅传递物理鼠标坐标，面板合并位移，16ms 定时器平滑显示并限制在垫内；静止、隐藏和关闭时停表，关闭退订移动事件。鼠标、点击猫爪及镜像缩放共用原坐标层。
