# v0.2.5 像素重绘与预览优化

## 新皮肤

新增可选「像素猫 · 重绘版」pixel_redraw。保留旧 pixel 的身体、眼球素材、默认皮肤 id 和用户已保存的选择。在「设置 → 猫咪 → 外观风格」选择新皮肤即可切换，推荐显示大小为 128px。

通过内置 image_gen 探索九姿态，修订多余手部和木桩后，使用仓库素材编译器生成真正的 64×64 硬边位图。九状态共用 16 色调色板、二值 alpha 和整数像素微动，全部 PNG 共 34,846 字节。原画及提示词在 `neko-assets/reference/pixel_redraw/README.md`。

当前没有独立眼神追踪和完整逐帧步态；旧版皮肤与既有能力保留。

## 已确认并修复的预览问题

1. 小像素图只会缩小不会放大，再经过 96→48 的设置控件缩放后显得过小。现在按非透明包围盒等比填入预览。
2. 预览只取身体图，遗漏独立眼球层。现在按所选状态的 eyeLayer 合成眼睛。
3. files 布局没有优先取 neko_idle_0.png，会误选按字典序排在前面的攀爬帧。现在遵循布局选择待机首帧。
4. 柔光皮肤独立帧实际为 128×128，清单为逻辑 32×32；预览截取左上角 32×32，导致内容为空。现在与宿主一致，使用独立帧的完整位图。

六项离线测试覆盖上述问题，以及透明像素不应占用调色板、新皮肤颜色/alpha/完整性/动画边界契约。测试已加入 tools/ci.py，Pillow 依赖记录在 tools/requirements-art.txt。预览脚本不再硬编码开发机路径。

全部 11 套皮肤的 thumb.png 已重新生成，运行身体帧仅新增 pixel_redraw。
